Before downloading

Quick answers.

Which file should I download?

Use the main button. It prefers a Forge zip, then a setup installer, and ignores updater-only files like blockmaps and latest.yml.

Do I need latest.yml?

No. That file is for Forge auto-update. Users only need the setup or zip package.

What if the newest channel has no package?

The site shows the newest channel name, then uses the newest downloadable Forge asset it can find.

Why does Windows warn on install?

New Windows apps can show SmartScreen warnings. Use only this site or the official GitHub release link.

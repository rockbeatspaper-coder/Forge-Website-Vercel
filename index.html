FAQ

Questions users actually ask.

Which file do I download?

Use the main Forge setup or the public Forge zip. You do not need to manually download latest.yml or the blockmap.

Why is there a latest.yml file?

That file is for Forge auto-update. The app reads it from GitHub releases in the background to find the newest build.

What if Forge says it is up to date?

That usually means the uploaded updater version is not higher than the installed version, or GitHub has not finished serving the new release assets yet.

Where does Forge install?

The installer uses the standard Forge install path and includes the Electron client, backend resources, app icon, shortcuts, and updater metadata.

How do updates work?

Forge checks GitHub on launch. When a newer version is available, it shows the update prompt, installs in the background, relaunches, and shows an installed notification.

What if update files are missing?

Forge shows a repair popup that points users to reinstall with all required files instead of leaving the updater stuck.

Does Forge include a script hub?

Yes. The client has a Script Hub page designed around searching, previewing, inserting, and running scripts from a dedicated workflow.

Does the editor support Luau?

The editor uses Monaco with Lua/Luau-focused highlighting, snippets, diagnostics, tabs, and a Lua 5.1 runtime label in the statusbar.

Why does Windows warn on install?

New or unsigned Windows apps can trigger SmartScreen-style warnings. Make sure you are using the official Forge release link from this site or GitHub.
